# YouTube Landing Page Clone

A responsive clone of the YouTube homepage built with HTML, CSS, and vanilla JavaScript.

## Features

- Fixed header with logo, search bar, and action buttons
- Collapsible sidebar navigation with subscriptions
- Category filter chips
- Responsive video grid with thumbnails, durations, and metadata
- Mobile-friendly layout with hamburger menu

## Getting Started

Open `index.html` in your browser, or run a local server:

```bash
npx serve .
```

Then visit `http://localhost:3000`
